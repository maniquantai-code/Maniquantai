# ManiQuantAI MT5 Bridge EA

`ManiQuantAI_MT5_Bridge.mq5` is the MetaTrader 5 Expert Advisor that runs on the user's own Windows MT5 terminal.

## Important

The repository currently contains the **MQL5 source**. MetaTrader's MetaEditor must compile it into `ManiQuantAI_MT5_Bridge.ex5`; an `.ex5` binary is not generated by GitHub/Vercel.

## User installation

1. Download `ManiQuantAI_MT5_Bridge.ex5` from the ManiQuantAI dashboard after the SaaS publishes a compiled release.
2. In MT5 choose **File -> Open Data Folder**.
3. Open `MQL5/Experts/` and copy the EA into that folder.
4. Open MetaEditor and compile the `.mq5` source if compiling locally, or restart/refresh MT5 after installing the `.ex5`.
5. In MT5 open **Tools -> Options -> Expert Advisors** and add the ManiQuantAI API origin to **Allow WebRequest for listed URL**.
6. Attach **ManiQuantAI MT5 Bridge** to a chart.
7. Enter the user's personal Bridge Token in the EA inputs.
8. Enable **Algo Trading**.

## Security model

- Never put the Supabase service-role key in the EA.
- Each user should receive a scoped bridge token from ManiQuantAI.
- The EA sends the token using HTTPS authorization and does not need the user's broker password.
- The user's MT5 terminal remains the local execution environment.
- Live execution must remain gated by ManiQuantAI's server-side approval system.

## API compatibility

The EA is aligned with the existing bridge agent's execution endpoints:

- `GET /api/mt5-bridge/jobs`
- `POST /api/mt5-bridge/heartbeat`
- `POST /api/mt5-bridge/execution/{job_id}/complete`
- `POST /api/mt5-bridge/execution/{job_id}/fail`

The existing Python bridge already documents the same polling model and job completion/failure endpoints.
